# ContractWatch — API Contracts & Change Detection

**Category:** API & System Integration  
**Status:** New independent working project; no client affiliation or production monitoring history claimed.

## Description

ContractWatch explains why an API integration fails, even when an endpoint remains reachable. It sends real HTTP requests and checks expected status, response time, valid JSON and required typed fields. Stored responses and path-level differences give developers evidence of what changed between requests.

The dashboard connects each endpoint to its exact failed requirement, with inspectable history, CSV export and a command-line entry point. Contract versions preserve earlier configurations and results. Eleven automated tests cover missing fields, type changes, HTTP errors, invalid JSON, latency, persistence and request restrictions

This independent application demonstrates integration testing and fault diagnosis using disclosed verification inputs. Checks run on demand; scheduled monitoring and alert delivery are outside its scope. Remote authenticated use requires trusted destinations, and public deployment requires additional access controls and operational hardening.

**Skills:** API testing, system integration, HTTP, JSON validation, Python, SQLite, change detection, debugging, HTML/CSS/JavaScript.
